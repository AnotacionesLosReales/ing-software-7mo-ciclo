# Semana 11: Applications Integration

## Integración

- **Enterprise Integration (EI)**: Capacidad de integrar infomación y funcionalidad de varios sistemas en una empresa.
- **Enterprise Application Integration (EAI)**: Integración a nivel de la lógica de la aplicación.
- **Aplicación de Integración y Middleware (AIM)**: Diferentes empresas, data operacional, data no estructurada, AIM incompatible.

Depende de:
- El nivel o vista arquitectónica del sistema de información.
- El contenido y funcionilidad de los componentes.
- El tipo de información manejada por los componentes (alfanumérica, multimedia, estructurada, semi-estructurada, no estructurada).
- Requisitos de autonomía.
- Uso de sistema integrado.
- Requisitos de desempeño.
- Recursos disponibles (tiempo, dinero, recursos humanos, conocimiento, etc.).
