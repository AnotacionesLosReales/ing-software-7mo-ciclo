# Semana 6: Continuous Integration on Testing

## jMeter

- Apache JMeter se puede usar para probar el rendimiento aplicaciones dinámicas web.
- Se puede usar para simular una carga pesada en un servidor, grupo de servidores, red u objeto para probar su resistencia o para analizar el rendimiento general bajodiferentes tipos de carga.

## Veeam Data Platform

- Es una solución integral de protección, respaldo y recuperación de datos diseñada para garantizar la continuidad del negocio y la ciberresiliencia en entornos híbridos y multi-nube.
- Unifica el backup, la recuperación y la seguridad de cargas de trabajo virtuales, físicas, en la nube y SaaS (como Microsoft 365).

## Selenium IDE

- Es una herramienta de automatización de pruebas de código abierto que permite grabar y reproducir tus acciones en la web.
- Con ella, se pueden automatizar las pruebas **funcionales** de aplicaciones web.

## Jenkins

- Jenkins es un servidor de automatización de código abierto, basado en Java, fundamental para la Integración Continua (CI) y Entrega Continua (CD).
- Permite automatizar la construcción, pruebas y despliegue de software, acelerando los ciclos de desarrollo y detectando errores tempranamente mediante pipelines.

## SonarQube

- Es una plataforma de código abierto líder en análisis estático para inspeccionar continuamente la calidad y seguridad del código fuente (Clean Code).
- Detecta automáticamente errores, vulnerabilidades y deuda técnica en más de 30 lenguajes, ayudando a los equipos a mantener software seguro y sostenible.
