# Semana 11: User Data Analytics

## User Analytics

- Método para analizar a los usuarios de productos digitales como apps o software platforms.

### How do user analytics work?

- User analytics actúa como un hub que conecta muchas fuentes de datos.
- Central repository que extrae datos de la app o service, hosting platforms, advertising partners, app stores e internal databases haciéndolos accesibles.

## User Analytics Platform

- También llamado product analytics.
- Tipo de software que realiza user analysis y evidencia insights más allá de lo que los productos de software pueden normalmente proporcionar por sí mismos.
- Permite a los equipos construir productos con los que los usuarios se vinculen más, elevando la rentabilidad
- User analytics platforms tienen tres capacidades principales.
  - Data collection and storage
  - Analysis and recomendation
  - Testing and marketing
 
### Data collection and storage

- Automatizan la recolección de datos.
- Proporcionan integraciones para recolectar datos de diversas fuentes con frecuencia mensual, semanal y en algunos casos en tiempo real.
- Almacenan su data de forma simple, segura y escalable, facilitando con ello su análisis.

### Analysis and recommendation

- Muchos product teams acceden a user analytics a través de sus interfaces web.
- Proporcionan herramientas para reportes de datos y construir dashboards para mantener a sus empleados organizados en los equipos y business units.

### Testing and marketing

- Ayudan a product teams evolucionar el producto al ritmo de las preferencias de los usuarios.
- Ofrecen herramientas para A/B & multivariate testing, analizando hipótesis y mejorando el user journey probando nuevos forms, textos, imágenes y workflows.
- Automatizan el testing para que el producto se auto-optimice.
- Algunas incluyen capacidades de marketing automation, para que los product teams apliquen estrategias de comunicación hacia los usuarios, vía messages, in-app messages, push notifications, email.

## KPIs

### Retention Rate

- Para calcular el retention rate es necesario determinar cómo se planea medirlo:
  - Basado en total number of customers o total revenue
  - Period: Medido mensual, trimestral, anual o total
 
**Customer retention equation**

```
Retention rate = ((Number of customers at the end of period – Number of customers acquired during period) / Number of customers at start of period) x 100
```

### Gross Revenue Retention Rate (GRR)

- Porcentaje de recurring revenue retenido de existing customers en un periodo definido, incluyendo downgrades y cancels. No incluye expansion revenue.

**GRR equation**

```
RR (Recurring revenue) al inicio del periodo – Downgraded RR durante el periodo –Cancelled RR durante el periodo) / (RR al inicio del periodo)
```
