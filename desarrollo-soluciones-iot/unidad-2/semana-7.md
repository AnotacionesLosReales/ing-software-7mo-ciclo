# Semana 7: IoT Edge & Cloud Technologies - Part 2

## Study Case: Azure IoT Edge

### What is Azure IoT Edge

- Azure IoT Edge traslada el análisis de la nube y la lógica empresarial personalizada a los dispositivos para que la organización pueda centrarse en la información empresarial en lugar de la administración de datos.
- Permite ampliar la solución de IoT empaquetando la lógica empresarial en contenedores estándar, para luego poder implementar esos contenedores en cualquiera de los dispositivos y monitorearlo todo desde la nube.

### Components

- IoT Edge Modules. Son contenedores que ejecutan servicios de Azure, servicios de terceros o su propio código. Los módulos se implementan en dispositivos IoT Edge y se ejecutan localmente en esos dispositivos.
- IoT Edge runtime. Se ejecuta en cada dispositivo IoT Edge y administra los módulos implementados en cada dispositivo.
- Cloud-based interface. Le permite monitorear y administrar de forma remota los dispositivos IoT Edge.

## Study Case: AWS IoT for the Edge

### AWS IoT

- AWS ofrece servicios y soluciones de Internet de las cosas (IoT) para conectar y administrar miles de millones de dispositivos.
- Permite recopilar, almacenar y analizar datos de IoT para cargas de trabajo industriales, de consumo, comerciales y automotrices.

### Services

- AWS IoT Greengrass extiende sin problemas AWS a los dispositivos perimetrales para que puedan actuarlocalmente sobre los datos que generan, mientras siguen usando la nube para administración, análisis y almacenamiento duradero.
- FreeRTOS es un sistema operativo en tiempo real de código abierto para microcontroladores que hace que los dispositivos periféricos pequeños y de bajo consumo sean fáciles de programar, implementar, asegurar, conectar y administrar.
- AWS IoT ExpressLink impulsa una variedad de módulos de hardware desarrollados y ofrecidos por socios de AWS, como Espressif, Infineon y u-blox.

Los módulos de conectividad incorporan los requisitos de seguridad exigidos por AWS, descargando el complejo trabajo de integrar las capas de conectividad, red y criptografía en la nube a los módulos de hardware, y permitiéndole desarrollar productos IoT seguros en una fracción del tiempo.
